# Package A R0 Summary

R0 freezes the exact Package A repository baseline and makes the capability boundary machine-visible.

- P1.5 discovery, CandidatePointer, STOP, explicit external selection, resolver continuity, and dual provenance are preserved.
- Skill 1.0's full-MAFS semantic claim is downgraded without discarding the earned substrate.
- Requirement fidelity, discovery purity, model-prior/evidence separation, and identity/proposition separation are mandatory Package A boundaries.
- E1's Hub-Lesion mechanism and E2 remain not earned/not authorized.
- R0-F0 authorizes a bounded source/content adapter; semantic sufficiency remains an implementation and Gate M3 target.
- `EpistemicRoute` is the sole new authoritative planning object in Package A; the legacy `Axis` runtime remains untouched for regression compatibility.

The baseline test run exposed an expected branch allow-list mismatch and a sandbox temporary-directory denial. Neither was classified as a functional regression. Package A adds the authorized branch and runs subsequent tests with an explicit repository-local pytest base temporary directory.
