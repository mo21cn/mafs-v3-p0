# Package A R1 Summary — EpistemicRoute

R1 introduces one authoritative planning object, `EpistemicRoute`. `Axis`
remains legacy vocabulary and is not a second source of execution truth.

Every route names its upstream requirement, semantic intent, evidence need,
search vocabulary, source requirement, independence rationale, framing
consequence, and uncertainty. A separate `RequirementRouteFidelityReview`
records `PRESERVED`, `CONTRACTED`, `DRIFTED`, or `UNRESOLVED`. Only
`PRESERVED` may execute; all other states fail closed.

Open-discovery artifacts recursively reject explicit expected-identity keys
and DOI-shaped targets. This is a safety boundary, not a mechanical scorer of
scientific quality. Semantic fidelity and scientific route quality remain
reviewed cognition and are externalized as artifacts.
