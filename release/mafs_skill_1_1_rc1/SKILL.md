# MAFS Skill 1.1

MAFS Skill 1.1 is the release-candidate product surface for the accepted
Post-P1.5 MAFS semantic engine. It consumes a frozen CQC artifact chain and
preserves requirement, authority, budget, and provenance lineage through:

Research Narrative → CQC → CQS → SRP → BudgetEnvelope → Package C binding →
MAFS Requirement → EpistemicRoute → live discovery → CandidatePointer → STOP →
explicit selection → SourceDocument → EvidenceSpan → PropositionEvidence →
CollisionAssessment (where applicable) → ResearchState → governed
re-digestion (where applicable) → EvidenceLandscapePackage.

The mandatory STOP boundary is not optional: discovery never selects or
resolves a candidate automatically. Model knowledge may propose routes; it is
not evidence.

This RC does not provide automatic top-1 selection, unbounded autonomous
recursion, automatic truth arbitration, research-opportunity ranking, ROC,
clinical decision support, autonomous experiment authorization, or production
decision authority.

RC1 is not production-released until Gate R1 acceptance.
